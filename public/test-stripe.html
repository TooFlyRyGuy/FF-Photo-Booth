⚠️ Setup Required

To test Stripe checkout, you need to:

  1. Create a Stripe product for "Starter Monthly" in your Stripe Dashboard
  2. Set the product metadata:
    • type: subscription
    • tier: starter
    • credits_per_period: 60
    • sms_credits_per_period: 50
    • prompts_limit: 5
    • rollover_enabled: false
  3. Create a monthly price of $29.00
  4. Copy the Price ID (starts with price_)
  5. Update the database with: UPDATE subscription_tiers_new SET stripe_price_id = 'your_price_id' WHERE name = 'Starter' AND billing_period = 'monthly';
